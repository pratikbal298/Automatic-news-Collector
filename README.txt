AUTOMATED DAILY NEWS COLLECTOR

Project Description:
This project is an automated daily news collector built using Python.

Technologies Used:
- Web Scraping using BeautifulSoup
- RPA Automation using Selenium
- CSV Data Storage using pandas
- Cron-style Scheduling using schedule library

Features:
1. Extracts latest news headlines automatically
2. Stores news data into CSV files
3. Automates browser actions using Selenium
4. Runs automatically using scheduling

Files:
- news_scraper.py → Basic web scraping
- selenium_news.py → Selenium RPA automation
- cron_news_collector.py → Automated scheduling
- news.csv → Stored news data

How to Run:
1. Activate virtual environment
2. Install requirements
3. Run desired Python file
